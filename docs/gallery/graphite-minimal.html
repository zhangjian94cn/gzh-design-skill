NOTE · 信息块和金句框

Callout 对比

这是 NOTE。用于补充背景、解释术语，视觉上应该轻，不要像警告一样重。

这是 IMPORTANT。用于承载核心判断，应该足够醒目，但不能破坏正文节奏。

NOTE

这是 WARNING。用于提示风险、限制条件和需要人工确认的地方。

这是 TIP。用于给出可执行建议，颜色和语气应当比 WARNING 更轻。
